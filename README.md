# School Task Tracker 📚

A simple web application for tracking student tasks and approvals, built with Flask and SQLite.

## ✨ Features

- **Task Tracking**: Record student task completions with grades
- **Multi-Class Support**: Different task lists per class
- **Excel-like Interface**: Sortable, filterable data table
- **Activity Log**: Real-time tracking of all actions
- **Mobile Friendly**: Works on all devices
- **Export to Excel**: Download data as formatted spreadsheets
- **Edit/Delete**: Full CRUD operations on records
